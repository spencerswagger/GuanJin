标准之间的冲突点

冲突点等保 2.0NIST SP 800-63B处理建议
口令定期更换 要求“定期更换”（二级 / 三级已明确） 不建议强制定期更换，认为会促使用户选择更弱、更好记的口令 二者取严：默认开启定期更换（可配关闭），并在策略说明中记录理由
口令复杂度 要求复杂度要求（组合规则） 更强调长度与弱口令黑名单，弱化组合规则 同时做：长度 + 复杂度组合 + 弱口令黑名单
生物特征 可作为“两种以上组合鉴别技术”中的一种 不得单独作为认证因素，必须与物理认证器组合 二者取严：生物特征在本平台不作单因素使用

来源全称、发布单位与原文入口

  1. GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》
    发布单位：国家市场监督管理总局、国家标准化管理委员会；主要起草单位含公安部第三研究所（公安部信息安全等级保护评估中心）等。
    原文入口：国家标准全文公开系统（检索标准号 GB/T 22239-2019） · 全国标准信息公共服务平台
  2. GB/T 39786-2021《信息安全技术 信息系统密码应用基本要求》
    发布单位：国家市场监督管理总局、国家标准化管理委员会。配套的测评依据为《商用密码应用安全性评估管理办法》及配套测评要求，由密码管理部门组织实施。
    原文入口：国家标准全文公开系统（检索 GB/T 39786-2021） · 国家密码管理局
  3. GB/T 37092《信息安全技术 密码模块安全要求》
    发布单位：国家市场监督管理总局、国家标准化管理委员会。用于判定“密码产品”是否达到密评所要求的安全等级（密评三级要求二级及以上）。
    原文入口：国家标准全文公开系统（检索 GB/T 37092）
  4. NIST SP 800-63B《Digital Identity Guidelines: Authentication and Lifecycle Management》
    发布单位：美国国家标准与技术研究院（NIST），隶属美国商务部。属 SP 800-63-3 系列，配套 SP 800-63A（注册与身份核验）、SP 800-63C（联邦与断言）。
    原文链接：https://pages.nist.gov/800-63-3/sp800-63b.html · SP 800-63-3 系列目录
  5. ISO/IEC 29115:2013《Information technology — Security techniques — Entity authentication assurance framework》
    发布单位：国际标准化组织（ISO）与国际电工委员会（IEC）联合发布，技术委员会 ISO/IEC JTC 1/SC 27（信息安全、网络安全与隐私保护）。
    原文入口：ISO Online Browsing Platform（检索 29115）
  6. ISO/IEC 27001:2022《Information security, cybersecurity and privacy protection — Information security management systems — Requirements》
    发布单位：ISO 与 IEC 联合发布，技术委员会 ISO/IEC JTC 1/SC 27。第 3 版，2022-10 发布；Annex A 含 93 项控制措施，分组织 / 人员 / 物理 / 技术四类。配套实施指南为 ISO/IEC 27002:2022。
    原文链接：https://www.iso.org/standard/27001 · IEC Webstore 条目
  7. OWASP ASVS《Application Security Verification Standard》
    发布单位：OWASP 基金会（Open Worldwide Application Security Project）。与认证相关的主要是 V2 认证、V3 会话管理、V4 访问控制、V6 存储加密、V7 日志与监控。
    原文链接：项目主页 · GitHub 仓库（含各版本全文）
  8. OWASP Top 10 Proactive Controls（C7: Secure Digital Identities）
    发布单位：OWASP 基金会。用于补充“认证与会话管理”方面的工程实践建议；漏洞扫描与渗透测试的方法学参考（OWASP Testing Guide）。
    原文链接：https://top10proactive.owasp.org/

说明：国标类标准（GB / GB-T）的全文在“国家标准全文公开系统”按标准号公开提供，链接指向该系统的检索入口，实际阅读请在其中搜索对应标准号。密评的具体测评项判定由具备资质的测评机构现场出具结论；本表条文摘录用于设计自查，最终以标准原文与测评结论为准。
