## 关键实现决定（评审要点）
1. **Maven 版本语义 = 保守近似**（vuln-gate.py `vparse`）：`.RELEASE/.Final/.GA` 剥尾缀；`.SEC<n>/.SP<n>` 剥尾缀后末段 +n（5.3.39.SEC03 ⇒ 5.3.42）；`.RC/.M/Alpha` = 预发布；四段数字微版本（2.13.4.2）支持；五段以上 → None（红）。方向：只许误红不许漏报（对齐 #127 的 Go 口径）。
2. **分生态指纹**：快照头新增 `coords_sha256_go/npm/maven`（与全集同算法）。本地无 BOM（`make gates`）= 子集运行，按生态核对；CI 全生态运行查全集 `coords_sha256`（口径不变松）。
3. **白名单「不再命中」按参与判定的生态作用域化**：Maven 条目在无 BOM 的本地运行不判"不再命中"（否则本地 `make gates` 必红）；CI 永远带 BOM，收紧在那里生效。
4. **自有模块排除**：`group == metadata.component.group`（com.guanjin:guanjin-core/spring-boot2）两端（gate `read_java_bom` / refresh `collect_maven`）逐字一致，指纹才对得上。
5. **artifact 锚**：sdk job 写 `bom-commit.txt=$GITHUB_SHA`，vuln job 逐字节核对（D23③② "早于本次 commit = 红"）；artifact 仅本次 run 内有效 + `needs: sdk` 保证存在性。
6. **自检 24→35**：Maven/BOM 11 项（HIGH 命中红点名 `bom.json:<组件序号>` / 修复版绿 / 无 BOM 显式 UNCOVERED / 缺失红 / 坏 JSON 红 / 0 组件红 / 全自有模块红 / MODERATE 仅提示 / MAL 红 / 四段微版本命中红 / 无 BOM 不误判不再命中）。ci.yml 断言恰 35。
