# `gateway.jwks-uri` 同源校验的裁定与执行形态（2026-11-10）

> **性质**：基线**释义 + 执行形态**记录，不是契约变更、不是判据变更。裁定人 = **Spec**（基线释义负责人）；入库转录 = Ark（2026-11-10）。被 `sdk-contract.md` §3.2 #12 那一格与本文件互相引用，路径固定为 `notes/sdk-jwks-uri-同源校验-2026-11-10.md`，改名/移动要同步改 `docs/sdk-contract.md` 的引用。
>
> **一句话结论**：SDK 启动期校验 `guanjin.gateway.jwks-uri` 与 `guanjin.platform.base-url` **同源**（`scheme` + `host` + `port` 一致），不一致即**启动失败**；这是**执行既有安全约束**（加固），**不进 CH、不动判据与 90 项账目**，**不得**为它新增任何开关。

## 1. 它执行的是哪条已冻结约束

`docs/sdk-contract.md` §3.2 第 **12** 行（`guanjin.gateway.jwks-uri`）的「安全约束（三语言同）」列早已冻结：

> **只允许平台 JWKS 基址口径**（C-2）；旧值 `/api/v1/jwks` **全库不存在**、首启 404 → 禁写；**跨域/第三方地址 = 换信任源，需 ADR**。

冻结的是「**只许平台自己的 JWKS 基址**」这个**结论**，但原文没写**怎么执行**。缺执行形态时，实现方会各自决定（有告警放行、有静默沿用、有只做首启一次），等于把冻结约束做成软约束。

## 2. 执行形态（唯一口径，三语言同）

| 项 | 口径 |
|---|---|
| 校验时机 | **SDK 启动期**（首次装配 `AssertionVerifier` / 拉 JWKS 之前），与 `AC-SDK-03`（首启必须命中真实 JWKS）同一阶段 |
| 比较对象 | `guanjin.gateway.jwks-uri` vs `guanjin.platform.base-url` |
| 判等维度 | **`scheme` + `host` + `port` 三者一致**（port 按 scheme 的默认值归一后比较：`http`→80、`https`→443；`jwks-uri` 的路径部分不参与同源判定） |
| 不一致的后果 | **启动失败**（不是告警、不是降级、不是"仅首次不校验"） |
| 语言一致性 | Java / Node / Go 三语言**同一形态**；不存在"某语言可跳过"的开关 |

## 3. 为什么是「加固」而不是新增契约面

按 `docs/decisions.md:379` 的三分判据（`decisions.md` D6(5) 后的纠错/加固/变更边界）：

| 判据 | 本条 | 结论 |
|---|---|---|
| 新增 key / 改 key 名？ | 否（仍 29 项，编号 1..29 连续） | 不是变更 |
| 改默认值？ | 否（默认仍是 `${platform.base-url}/.well-known/jwks.json`，D6(3)/(5) 纠错性默认值不变） | 不是变更 |
| 改必填性？ | 否（仍「否」） | 不是变更 |
| 让业务方能用基线**原本不允许**的方式配置？ | **否**——基线本已禁止跨域/第三方地址；本条只是让"已禁止"变成**可执行**（启动即失败） | **加固**，不进 CH |

## 4. 硬边界（写死，防外延）

- **不动键名、不动默认值、不动必填性、不动 29 项计数**。
- **不加任何开关键**：`allow-cross-origin` / `same-origin-check.enabled` 之类**一律不许出现**——那等于给"换信任源"开生产后门（与 §九「不存在生产可跳过验签的开关」同源）。
- 不动判据文件（`acceptance-criteria.md`）、不动 90 项账目；**不需要 CH 登记**。
- 需要换信任源（接第三方 JWKS）时，走**新增 ADR**，不许拿配置项绕过。

## 5. 与判据的关系

- 本条**不新增判据**；它挂在既有 `AC-SDK-04`（平台地址缺失/非法 → 启动失败）与 `AC-SDK-03`（首启必须命中真实 JWKS）之下被执行与举证。
- 若日后 Gate 需要把它单独列成一条判据，属**判据文件变更**（需主持人确认 + 账目变动），本文件不预先记账。
