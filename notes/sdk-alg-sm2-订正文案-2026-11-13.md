## 二、不许动的地方（逐条列举，可复跑核验）

复跑命令（**分类而非计数**）：

```bash
git grep -nE "SM3withSM2|ALG_SM3_WITH_SM2|JCA_ALG" -- sdk/java
```

1. **oidc（对外令牌）轨一律不改**：`JwksKey.java:17` 常量 `ALG_SM3_WITH_SM2 = "SM3withSM2"`（当前零引用，属 P2 命名清理，随 #51 裁量，**不在本文范围**）；`assertion-vectors.json` 的 `oidcAlg` 向量 header/note = `SM3withSM2`（**负向用例的合法值**，改了就把"用户令牌 alg 不得验断言"这条测反）；oidc 键夹具（`oidc-2026-11`、`TestPlatform`）。
2. **`Sm2.JCA_ALG = "SM3withSM2"`（`Sm2.java:51`）不改**：它是 BC 注册的 **Signature 原语名**（OID 1.2.156.10197.1.501），**唯一 JCA 调用点 = `Sm2.java:100` `Signature.getInstance(JCA_ALG, BC)`**；D29 改的是 wire `alg` 标识，不是原语。把 JCA_ALG 也改成 "SM2" 会在 JCA 层 `NoSuchAlgorithmException`（→ 静默 401）。
3. **JWKS 的 `kty:"EC"` / `crv:"SM2"` 不动**（密钥类型，与 JWT `alg` header 值无关）。
4. **`migrations/000013` CHECK、平台 `keygen`、`internal/signing`、`docs/baseline/` 不动**——平台侧本来就是 SM2，零改动（D29）；`sdk-contract.md` 三处（§4.1 M2、§4.5 ②、§7 向量行）已由 Ark 在 #131 订正，Nova 不重复改。
5. **测试注释/夹具的口径病**（如 `JwksClientTest.java:48-49` 的注释）属 **P2**，随 #51 清理，不入本文案（Owl 已记录在案）。
